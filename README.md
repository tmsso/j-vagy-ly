# J vagy LY? — Hungarian j/ly spelling practice

A small web game for practising one of Hungarian spelling's classic traps: each round shows two spellings that differ only in `j` vs `ly` (e.g. `folyó` / `fojó`), and you pick the correct one. Words you miss come back more often until you master them.

**Live:** [j-vagy-ly.tmsso.com](https://j-vagy-ly.tmsso.com) (the original [j-or-ly.vercel.app](https://j-or-ly.vercel.app) keeps serving the same app)

## Features

- 16,285 generated word pairs (words up to 15 characters)
- A failed-word backlog: missed words reappear every 4th question after a short cool-down, turn green after 2 correct answers in a row, and are mastered (with confetti) after 4 correct
- Pairs where both spellings are real words ("Mindkettő helyes!")
- Score, accuracy and a top-3 list, stored locally in the browser
- Optional auto-advance after a correct answer (configurable, cancellable)
- Keyboard shortcuts: `1`/`2` or `←`/`→` to choose, `Enter`/`Space` for the next word, `N` (or the "Új játék" button) for a new game, `Esc` to close a dialog
- Installable as an app (PWA), and playable offline after the first visit
- Hungarian UI, responsive, no account and no tracking

## Tech stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS · Vercel. The word pairs are pre-generated by a Python script.

## Development

Prerequisites: Node.js 22+, Python 3.

```bash
git clone https://github.com/tmsso/j-vagy-ly.git
cd j-vagy-ly
npm install
npm run dev          # http://localhost:3000
```

`npm run verify` runs everything CI runs: lint, typecheck, Jest, the Python generator tests and the build.

`npm run build` regenerates `public/jly-pairs.json` from `data/magyar-szavak.txt` first (the `prebuild` step), then builds.

### Auto-advance

Correct answers show the next word after `AUTO_ADVANCE_DELAY_SECONDS` (default 5) in `app/constants.ts`. Set it to `0` to disable the feature and hide its checkbox. Any click or key press cancels a running countdown.

## Data pipeline

`scripts/generate-pairs.py` reads the dictionary and, for every word containing `j` or `ly`, builds a wrong variant by swapping one occurrence (`j↔ly`, `jj↔lly`). If the "wrong" variant is itself a real word, the pair is flagged `bothCorrect`. The output is committed as `public/jly-pairs.json`. Regenerate and commit it whenever the word list changes:

```bash
npm run generate-data
```

## Deployment

Vercel's Git integration builds every push. `main` goes to production, and other branches get preview URLs.
